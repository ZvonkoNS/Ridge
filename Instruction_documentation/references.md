# References

Last verified: 2026-10-16
Reference index for the standards used by this pack and by Ridge. Verify the current edition before citing a standard in a release, report or validation document.

## Standards version rule

Use the latest stable published edition the toolchain, contract and risk profile can support. Use drafts only when `Project_Standards_Profile.md` explicitly adopts them (none adopted today).

## Ridge-specific references

Forensic science and digital evidence:

- ISO/IEC 17025 - General requirements for the competence of testing and calibration laboratories.
- ISO 21043-1 to -5 - Forensic sciences (vocabulary; recognition, recording, collecting, transport and storage; analysis; interpretation; reporting).
- ENFSI Best Practice Manual for Fingerprint Examination; ACE-V.
- ISO/IEC 27037, 27041, 27042, 27043 - digital evidence handling, method assurance, analysis, investigation processes.

Biometrics:

- ISO/IEC 39794-4, 39794-2 - extensible finger image and minutiae formats.
- ISO/IEC 19794-4, 19794-2 - finger image and minutiae formats (earlier generation).
- ANSI/NIST-ITL 1-2025 (SP 500-290e4); ANSI/NIST-ITL 1-2011 Update 2015 (SP 500-290e3).
- ISO/IEC 29794-4 and NIST NFIQ 2: https://pages.nist.gov/NFIQ2/
- ISO/IEC 24745, ISO/IEC 19795-1, ISO/IEC 30107-1.
- Open matchers for validation (not verified): SourceAFIS https://sourceafis.machinezoo.com/ ; NIST Biometric Image Software (NBIS: mindtct, Bozorth3) https://www.nist.gov/services-resources/software/nist-biometric-image-software-nbis
- Method source of the pipeline: L. Hong, Y. Wan, A. Jain, "Fingerprint image enhancement: algorithm and performance evaluation", IEEE Transactions on Pattern Analysis and Machine Intelligence 20(8), 1998.
